= Changelog

This timeline records user-visible changes to `@dev-centr/themed-svg`.

== 0.2.0 — 2026-09-09

* Added a versioned JSON and streaming JSONL stdio protocol for native editors.
* Added inspect, validate, transform, fail-closed sanitize, and deterministic
  multi-artifact export operations backed by the canonical transformer.
* Added selector, binding, request-path, and XML location context to diagnostics
  where available.
* Published protocol TypeScript APIs and JSON Schema package exports.

Details:
link:changelog-details/2026-09-09-native-editor-protocol.adoc[Native editor
protocol].

== 0.1.1 — 2026-09-08

* Added progressive enhancement for portable adaptive `<img>` diagrams.
* Added deterministic `.svg` to `.host.svg` source derivation and batch image
  upgrades.
* Kept fallback images visible until sanitized host output loads and after
  first-load errors.
* Documented the source, manifest, adaptive artifact, and host artifact build
  convention.
* Fixed tag publishing to install Chromium for browser tests and detect
  already-published versions without registry credentials.

Details:
link:changelog-details/2026-09-08-progressive-diagram-upgrades.adoc[Progressive
diagram upgrades].

== 0.1.0 — 2026-09-08

* Established the independent version 1 semantic theming manifest and JSON
  Schema.
* Added safe structural transformation for attributes, inline CSS, stylesheet
  declarations, and gradient stops.
* Added standalone-adaptive, host, fixed, and paired-fixed output contracts.
* Added deterministic five-layer palette precedence and bundled light/dark
  defaults.
* Added CLI, diagnostics, browser behavior tests, and npm package boundaries.
* Required real or numerically derived SVG geometry; missing geometry now
  returns an error without output.
* Made host-mode output the API and CLI default and added the sanitizing
  `<themed-svg>` runtime bridge as the recommended web delivery path.
* Added a self-contained browser ESM registration bundle, explicit runtime API,
  strict source/redirect/size/MIME policy, shadow isolation, accessible naming,
  and race-safe reload behavior.
* Hardened transformation against injectable palette values and SMIL mutation,
  with a second completed-output safety pass.

Details: link:changelog-details/2026-09-07-initial-standard.adoc[Initial
semantic theming standard] and
link:changelog-details/2026-09-08-runtime-themed-svg-bridge.adoc[Runtime themed
SVG bridge].
