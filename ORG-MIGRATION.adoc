= Owned-organization diagram migration ledger
:toc:
:toclevels: 2

This ledger records the September 2026 migration from fixed or page-isolated
diagram SVGs to editable Mermaid source, explicit Themed SVG manifests,
standalone-adaptive assets, and progressively injected host assets.

The audit classifies authored SVG and inline SVG material before conversion.
Logos, icons, decorative art, UI mockups, generated status cards, fixtures, and
inherited fork assets remain outside the diagram migration. A fork is included
only when Ryan Johnson's commits introduced or materially changed the diagram.

== Artifact contract

Each migrated diagram keeps:

* `name.mmd` as editable source;
* `name.theme.json` as semantic bindings and palette metadata;
* `name.svg` as the portable standalone-adaptive asset;
* `name.host.svg` as the sanitized runtime-injection asset; and
* the previous fixed asset when it remains useful for uploads or comparison.

Owned sites reference `name.svg` in source and progressively upgrade marked
images to `name.host.svg`. Failure or absent JavaScript leaves the portable
asset visible.

  PolyglotScan, RepoLab, and formatte; none are relationship diagrams.

== Verification gate

A migration set is complete only after source regeneration is deterministic,
`--dual-output --check` passes, both adaptive color-scheme renders and both
manual host modes are readable, XML and accessibility checks pass, affected
site builds pass, generated copies are synchronized, and repository commits
are pushed.

== Completion record

The initial migration completed on 2026-09-08.

* `@dev-centr/themed-svg` `0.1.1` supplies progressive fallback upgrades.
* `@dev-centr/mermaid-svg-css-vars` `0.1.2` supplies atomic dual output and
  freshness checking.
* Sixty-four genuine diagram families now have Mermaid source, explicit
  manifests, standalone-adaptive SVGs, host SVGs, and retained fixed originals.
* Two additional UI/legend families remain hand-authored but now ship adaptive
  and host-safe themed forms without being misclassified as Mermaid diagrams.
* Canonical PlayTime output is pinned to the general-knowledge source and
  synchronized into Scriptbook, DevCentr specifications, Equivalence Engine,
  and devcentr.org without duplicating editable source.
* OpenShell, Dlang Supplemental, FoodTruckNerdz, HCI Nerdz, Desktop Tooling,
  Connectome FS, and DevCentr hub deployments passed after migration.
* Every migration commit is reachable from its repository's remote default
  branch. The modified FoodTruckNerdz fork was merged through a ready-for-review
  pull request; no draft pull request was used.

Some primary local checkouts were concurrently used by other work during this
migration. Those unrelated dirty trees were not reset, staged, or committed.
Isolated worktrees supplied clean source-of-truth commits and remote validation
where shared checkouts were unsafe.
